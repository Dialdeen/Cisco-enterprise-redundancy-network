## Device Access & Default Credentials

Use the credentials below to log into the virtual appliances and management interfaces once the topology is running in GNS3:

| Device / Appliance | Interface / Service | Username | Password |
| :--- | :--- | :--- | :--- |
| Main Router  | `admin` | `Admin123` |
| GNS3 Server / VM | Web UI | `gns3` | `gns3` |

## Quick Start
1. Download or clone this repository.
2. Open GNS3 and select **File -> Import portable project**.
3. Load the `.gns3project` file from this folder.
4. Start the nodes and access the devices using the credentials above.
